# tree-sitter-bronze

A [tree-sitter](https://tree-sitter.github.io) grammar for Bronze 0.1, used for highlighting in Neovim.

It follows [doc/spec-0.1.md](../../doc/spec-0.1.md), but more loosely than the real parser: newlines are ignored (except after a bare `return`), and there are no type rules. It only needs to be right for valid programs.

| File | What |
|---|---|
| `grammar.js` | the grammar; edit this |
| `src/` | generated by `tree-sitter generate`; committed, because Neovim builds the parser from `src/parser.c` |
| `queries/highlights.scm` | highlight captures, with Neovim's capture names |
| `test/corpus/` | tree-sitter tests: source, then the expected tree |

## Working on the grammar

From the repository root:

```
make tree-sitter      # generate, run the corpus tests, and parse every valid .brz program
```

This needs the tree-sitter CLI (`npm install -g tree-sitter-cli`).

On macOS, if building fails with `ld: tapi error: malformed file` or `unknown architecture`, the linker is older than the Command Line Tools SDK. The Makefile avoids it by setting `SDKROOT` to Xcode's SDK; do the same when running `tree-sitter` by hand:

```
SDKROOT=$(xcrun --sdk macosx --show-sdk-path) tree-sitter test
```

## Neovim

1. Build the parser and install it with the queries into `~/.local/share/nvim/site`, which Neovim searches by default:

   ```
   make nvim-install
   ```

   This writes `~/.local/share/nvim/site/parser/bronze.so` and `~/.local/share/nvim/site/queries/bronze/highlights.scm`. Run it again after changing the grammar or the queries.

2. Tell Neovim that `.brz` files are Bronze, for example in `init.lua`:

   ```lua
   vim.filetype.add({ extension = { brz = "bronze" } })
   ```

3. Start tree-sitter highlighting for the buffer. If your config doesn't already do it for every filetype:

   ```lua
   vim.api.nvim_create_autocmd("FileType", {
     pattern = "bronze",
     callback = function(args) vim.treesitter.start(args.buf) end,
   })
   ```

Check it with `:InspectTree` or `:Inspect` in a `.brz` file.
