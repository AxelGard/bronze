# tree-sitter-bronze

A [tree-sitter](https://tree-sitter.github.io) grammar for Bronze 0.2, used for highlighting.

It follows [doc/spec-0.1.md](../../doc/spec-0.1.md) and [doc/spec-0.2.md](../../doc/spec-0.2.md), but more loosely than the real parser: newlines are ignored (except after a bare `return`), and there are no type rules. It only needs to be right for valid programs.

| File | What |
|---|---|
| `grammar.js` | the grammar; edit this |
| `src/` | generated by `tree-sitter generate`; committed, so that editors can build the parser with only a C compiler |
| `queries/highlights.scm` | highlight captures, with Neovim's capture names |
| `test/corpus/` | tree-sitter tests: source, then the expected tree |

The grammar lives in the Bronze repo so that it changes together with the language. Editors can install it from this subdirectory (nvim-treesitter's `location`, Helix's `subpath`).

## Working on the grammar

From the repository root:

```
make tree-sitter      # generate, run the corpus tests, and parse every valid .brz program
```

This needs the tree-sitter CLI (`npm install -g tree-sitter-cli`). After changing the grammar, run `make install` to rebuild the parser for Neovim (it runs `bronze setup nvim`, which compiles the `src/parser.c` built into `bronze`).
