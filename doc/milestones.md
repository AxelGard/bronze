# Milestones

## 1. First compiler: `core.brz`

The first Bronze compiler (or interpreter) is done when it runs [`core.brz`](../exampels/core.brz) and prints exactly the expected output listed at the bottom of that file.

It covers: functions, recursion, `con`/`mut`, `Int`/`Float`/`Bool`/`String`, arithmetic, comparisons, `and`/`or`/`not`, `if`/`else if`/`else`, `while`, `Float(x)`, string `+`, `print`, comments, and `main() -> Int`.

Not included: classes, data classes, namespaces, errors, `null`, lists, `for`, string interpolation, default parameters, imports, `shell`.
